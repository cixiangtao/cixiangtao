## 关于我

我是一名前端工程师，常驻北京。日常主要使用 TypeScript、React、Vue、Vite 和 Node.js，也会持续关注开发体验、类型安全、可维护性与界面细节。

这里既是我的 GitHub 主页，也是个人工作台的入口：项目记录我正在构建的东西，文章保存实践过程、设计取舍与阶段复盘。
